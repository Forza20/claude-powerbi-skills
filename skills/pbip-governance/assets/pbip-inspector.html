Azure DevOps Wiki bundle

Downloads a .zip with a folder structure ready for Publish code as wiki — includes .order files, Mermaid flowcharts (relationships + data lineage), collapsible DAX sections, auto-TOC, and :warning: badges on PII/RLS pages. All Mermaid uses the :::mermaid fence that Azure DevOps expects.

How to publish
1. Unzip into a folder in your Git repo (e.g. /wiki/)
2. Commit and push to Azure DevOps Repos
3. In Azure DevOps → Overview → Wiki → Publish code as wiki
4. Point at your repo, branch, and the wiki folder → Publish
